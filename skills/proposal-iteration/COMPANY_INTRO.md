# 次元創意「公司介紹」模板 · 分案件類型 Track A / B

> 沉澱自製造業客戶（系統案）+ 線上課程客戶（前端網頁案，客戶=教育客戶）兩個實戰。
> **同樣的大廠背景**，但對接不同市場、用不同 framing、報不同量級。

---

## 第一步：判斷案件 Track

**先決定本案是哪種 track，再選對應模板**：

| 訊號 | Track A · 系統案 | Track B · 前端網頁案 |
|---|---|---|
| 客戶要的核心 | 多角色 / 流程 / 資料庫 / 後台 | Landing page / 品牌官網 / 設計感 |
| 價格量級 | 48 萬 – 158 萬+ | 2.8 萬 – 15 萬 |
| 工期 | 2–5 個月 | 2–6 週 |
| 核心賣點 | 系統穩 / 資料保得住 / 12 個月自動跑 | 設計品質 / 招生轉換 / 動畫精緻 |
| 維運 | 8K–25K/月（強推 recurring） | 通常無 / 單次交付為主 |
| 典型範例 | 製造業客戶 / 案件儀表板 / B2B 銷售自動化 | 線上課程客戶 / 協作徵稿平台徵稿 / 品牌官網 |
| 對應 skill | gen-pricing-proposal | gen-deal-doc / gen-demo-proposal |

**混合案**（例如：有 landing page + 簡單後台）：用 Track A 主結構但價格量級可能落 10–30 萬中間帶。

# Track A · 系統案模板（製造業客戶 風格）

## 三部曲節奏

```
03 · 市場對比頁         ← anchor 業界系統 SI 價格（120-250 萬）
   ↓
04 · About Us 次元創意   ← 3 卡片 + 相近案例 + 「為什麼接這個案」
   ↓
04b · Why Us 為什麼是這個價格 ← 5 段論述把報價封死
```

## A-① 市場對比表（系統案 5 條路線）

| 解決路線 | 業界價格區間 | 為何不選 / 本案位置 |
|---|---|---|
| **國際大廠 SaaS**<br>Workday / SAP SuccessFactors / BambooHR | 年費 50–200 萬<br>+ 導入 100–300 萬 | 模組固定、無法貼合 {客戶方法論}；長期成本 3-5 倍 |
| **國內 SaaS**<br>Apollo / Hubble / CakeHR / 104 HR | 年費 10–30 萬<br>+ 客製 50–150 萬 | {核心需求} 模組薄弱、不能承載您的方法論 |
| **本土 SI 客製化** ⭐ 傳統工程方法 | **120–250 萬** | ← **本案 B 標準版 {本案價格} 在此區間下緣** |
| **自建**（雇 1 PM + 1 工程師） | 90–150 萬 | {客戶身份} 不適合養 IT 團隊、18 個月後人員流失風險高 |
| **純套版**<br>Notion / Airtable + Zapier | 5–30 萬 | 無法處理多角色權限、{核心功能} |

### 結尾結論 box（黑底 + gold）

> 業界 SI 報這類系統 120-250 萬，因為他們用傳統工程方法 + PM/文件/業務/公司 overhead 的層層成本。
> 我們的 {主推價} 是 AI-native 工法 + 大廠工程師背景 — 同樣工程 3.5 個月做完傳統 6-9 個月、品質不打折、沒大公司 overhead。
> 價格反映的是「**團隊結構效率**」，不是「我們便宜在偷工」。

## A-② About Us · 3 卡片內容（系統案版）

```
① 大廠工程師團隊（白底）
   團隊來自 Appier / GoFreight / 字節跳動
   把大廠級方法論用在中小型專案上

② 按難度分工（白底）
   簡單任務 → 初階；複雜架構 → 資深；AI 整合 → AI 專家
   不用菜鳥做難題、不用資深做雜事

③ 全面導入 AI 加速 ⭐（黑底 + gold 文字）
   B 標準版 3.5 個月做完傳統團隊需要 6-9 個月
   速度由 AI、品質由人工把關
```

## A-③ Why Us 5 段論述（系統案永遠這 5 段）

01 · **這是「業務系統」不是「網站」** — 多角色 / 多時點 / 資料隔離
02 · **資料不能丟，是這套系統的底線** — 數千筆關鍵資料、資料保得住的保證
03 · **您買的不是專案，是長期夥伴** ← **必須引述會議原話**
04 · **AI-native 流程讓我們做得快也做得對** — 3.5 月 vs 6-9 月
05 · **這套系統是您的「商業放大器」** — ROI 願景

# Track B · 前端網頁案模板（線上課程客戶 / 教育客戶風格）

## 三部曲節奏（壓縮版 · 通常 1-2 頁完成）

```
P0X · Why Us 團隊背景      ← 3 卡片大廠（同 Track A）
       ↓
P0X · 市場價格對照          ← anchor 設計工作室 vs freelancer 區間
       ↓
P0X · 三方案 ABC 工法差異   ← 套模板 / 改原碼 / 重新設計
```

⚠️ Track B 因為案件規模小，**通常合併在 1-2 頁完成**，不像 Track A 鋪 3 整頁。

## B-① 市場對比表（前端網頁案 5 條路線）

> 競品換成「設計工作室 / 網頁公司 / freelancer / 套版」— 跟系統案完全不同的市場。

| 類型 | 價格區間 | 特色 / 限制 |
|---|---|---|
| **設計工作室**<br>板塊設計 / 平面良品 / 草字 | NT$ 25–40 萬 | 從零設計、品質高，但價格高、工期 2-3 個月 |
| **網頁公司客製**<br>awoo / 米特科技 / 巨耀 | NT$ 8–15 萬 | 有完整流程，但缺彈性、報價偏高 |
| **我們的方案** ⭐ | **NT$ {本案價格} ⭐** | **AI 加速 + 大廠經驗 + 拿原碼修改**，{X} 週交付 |
| freelancer 接案個人 | NT$ 2–5 萬 | 價格相當，但無流程、品質浮動、單人風險高 |
| 套版產品<br>Wix / SHOPLINE Landing / Strikingly | NT$ 9K–2 萬 | 限制多、品質一般、無客製空間 |

### 結尾核心價值主張（淺灰 box · 不用黑底）

> 我們落在「設計工作室」的 **1/5 價格**、「freelancer」的**同等價格** —
> 但提供**大廠級流程與 AI 加速**的優勢。對 {客戶身份} 來說，**這個區間 CP 值最高**。

## B-② About Us · 3 卡片內容（前端網頁案版）

```
① 大廠工程師團隊（白底）
   團隊來自 Appier / GoFreight / 字節跳動
   累積大型網站效能優化、AI 工具整合、招生轉換漏斗設計實戰
   離開大公司後組成小型工作室

② AI 加速 + 人工精修（白底）
   把過去做企業級產品的方法論用在中小型專案上
   重複勞動交給 AI、設計判斷由人

③ 拿原碼修改的工法 ⭐（黑底 + gold）
   保留原版動畫 100% / 招生工具齊全
   不是套模板、不是從零重做 — 是「精準改造」
```

⚠️ 第 3 張卡 Track B 強調**「工法」**（拿原碼修改），不像 Track A 強調 AI 加速倍率。

## B-③ Why Us 短論述（前端網頁案 · 3-4 段就夠）

01 · **為什麼 4 週能完成（傳統 1.5-2 個月）** — AI 加速 + 流程簡化
02 · **設計品質 vs 招生轉換並重** — 不只好看、要能讓人報名
03 · **拿原碼修改的工法優勢** — 保留動畫精緻 + 加新功能
04 · **單次交付清楚、無後續綁定** — 不收月費、不綁約

⚠️ Track B **不要寫 5 段長論述**（案件小、客戶沒耐心），3-4 段精準就好。

## B-④ 三方案工法差異（A/B/C 命名邏輯）

前端網頁案的 A/B/C 不是「規模差別」（A 基礎 / B 進階 / C 旗艦），而是「**工法差別**」：

```
A · 套模板    ← 把舊版視覺當模板套上新內容（最快、最便宜）
B · 改原碼 ⭐ ← 拿原始碼一行一行手動修改、保留動畫（推薦）
C · 重新設計  ← 同主題全新精美設計 + 完整後台（最複雜、最高檔）
```

⚠️ Track B 一定要解釋「為什麼價差這麼多」— 客戶看 28K → 35K → 45K 會問。
**標準回答**：因為 A/B/C **工法不同**，不是規模不同。

## 共通的文案語氣硬規則（兩 track 都要）

✅ **永遠用 anchor**：具體 brand name / 具體數字 / 具體案例 / 具體會議原話
❌ **永遠避**：「資深團隊 / 業界經驗 / 品質不錯 / 市場上很多」（無 anchor = 客戶呵呵）

✅ **永遠保留**：Appier / GoFreight / 字節跳動 三 brand
❌ **永遠不要**：用「曾任職某大廠」這種無 brand name 寫法

✅ **永遠對比**：「我們 X 個月 vs 傳統 Y 個月」「我們 X 萬 vs 業界 Y 萬」
❌ **永遠不要**：自我宣稱「快」「便宜」「品質高」沒對比錨點
